Core Architecture: Ephemeral Directed Acyclic Graphs (DAGs)

T o eliminate cloud telemetry while preserving non-linear intellectual flow, conversational context cannot be stored as a flat array. Instead, treat each user exchange as an immutable cryptographic node linked backwards to its respective parent vector.

By isolating state transitions entirely within volatile memory (RAM heap), every spontaneous branch instantiates a separate lightweight pointer. Pruning a line of thought simply releases references, allowing instant garbageless wipe.

struct ThoughtNode {
    id: NodeId,
    parent: Option<Arc<NodeId>>,
    context_snapshot: Vec<Token>,
    state_mask: EphemeralMask,
}

impl ThoughtNode {
    fn fork_branch(&self, prompt: &str) -> Self {
        // Zero disk IO; COW reference in RAM
        Self::spawn_child(self.id, prompt)
    }
}
