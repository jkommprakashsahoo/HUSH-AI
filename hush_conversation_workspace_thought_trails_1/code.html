Core Architecture: Ephemeral Session DAGs

Traditional dialogue chains enforce rigid sequential arrays, causing state pollution whenever a user pivots intellectual perspective. To achieve seamless anonymous exploration, represent the conversation as an in-memory Directed Acyclic Graph (DAG) where each turn references its unique ancestor pointer.

Guiding Invariants
  1. Client-Side Isolation: The state graph exists solely inside volatile WebAssembly memory or session storage.
  2. Non-Destructive Forking: Branching creates isolated child references without recalculating parent turns.
  3. Zero Trace Teardown: Tab termination dispatches cryptographically verified zero-fill purge handlers.

When you initiate a branch, the model context window isolates the exact ancestor slice up to the selected node, passing zero extraneous tokens from sister branches.
