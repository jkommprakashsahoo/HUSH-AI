Core Architecture: Ephemeral Directed Acyclic Graphs (DAGs)

Traditional dialogue chains enforce rigid sequential arrays, causing state pollution whenever a user pivots intellectual perspective. To achieve seamless anonymous exploration, represent the conversation as an in-memory Directed Acyclic Graph (DAG) where each turn references its unique ancestor pointer. When a thinker branches, the model isolates that exact ancestral lineage without carrying irrelevant context vectors.

By maintaining atomic node immutability, branching forks do not duplicate prompt payloads. Instead, each child node appends a virtual branch pointer τ_child = f(τ_parent, δ_prompt), enabling frictionless cognitive wandering across divergent hypotheses.
